A FEW THINGS TO KNOW

你可能想知道

开始之前，先把小疑问放下。

iPhone 可以安装吗？

以本页下载区的实时发布状态为准。iOS 仅通过 App Store 或 TestFlight 提供安装入口；Android 的 APK 无法在 iPhone 或 iPad 上安装。

为什么扫码后没有自动安装？

二维码会打开官网下载区，由你点击安装入口。Android 下载完成后仍需要打开 APK 并在系统中确认。如果使用微信或 QQ 扫码，请从右上角菜单选择“在浏览器中打开”。

没有网络时，还能使用吗？

经文与本地学习功能可离线使用。圣经录音与诗歌需要先在联网时下载完成；收藏歌曲不会自动下载音频。在线目录、每日照片和检查更新需要网络。

更新会清除我的收藏和学习记录吗？

使用本站同一签名、兼容版本的安装包覆盖更新，会保留当前设备的应用数据。不要先卸载，也不要清除应用存储；这些操作会移除本地学习记录和下载。当前没有个人资料云同步。

经文、录音与诗歌来自哪里？

当前经文与圣经录音来自 chineseandenglishbible.com，采用英文 NIV 与 WordProject 普通话和合本等来源资源。各项内容版权归原权利人所有，使用受来源条款约束。诗歌版本与来源在 App 对应资料中说明。查看内容来源与使用说明。

遇到问题时，怎样反馈更有效？

请向为你提供 Selah 的维护者附上 App 版本、手机型号、系统版本和重现步骤；播放问题请补充书卷章节或歌曲名称。不要发送密码或私密学习资料。独立的公开反馈渠道尚未开放。
